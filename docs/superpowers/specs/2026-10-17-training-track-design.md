## 1. 왜 바꾸는가

이전 설계(5-Day 순환)는 네 영역을 하루씩 돌렸다. SKVA 자료의 언어로 보면 세 가지가 어긋난다.

1. **과제 분해.** 복식호흡·빨대·모음 유지·메트로놈 음절은 실제 말하기의 정보(상대, 문장 앞뒤, 시간 압박)가 빠진 과제다(6교시 3부 "밀가루·계란·설탕"). 전이될 공통 관계가 없다.
2. **특이성 위반.** 영역당 노출이 1/4이고 같은 영역이 5세션 뒤에 온다. 분산이 아니라 "한 번 하고 잊기"다. 9교시: 학습은 직후가 아니라 7일 뒤, 11주 뒤에 보인다.
3. **지표가 목표가 됨.** 녹음마다 점수를 보여주면 점수가 잘 나오는 조건(짧게·작게·단조롭게)으로 연습한다(6교시 7쪽, 9교시 굿하트).

## 2. 결정

| # | 결정 | 근거 |
|---|---|---|
| D1 | 한 번에 **한 고민(트랙)**만 훈련한다 | 특이성·분산, 8교시 "문제를 구체적으로", 1교시 "조절점 하나" |
| D2 | 트랙은 **전이 사다리** 6단을 오른다 (아래 표) | 5교시 캐리어-변조 계층, 6교시 전이 사다리 |
| D3 | 첫 세션은 **진단**: 사다리 1~4단을 올라 처음 흔들리는 계단(행동경계)을 찾고 고민을 제안한다 | 6교시 "실패 지점이 다음 조절 조건", 4교시 학생 1·2·3 |
| D4 | 고민은 앱이 제안하고 **사용자가 확정**한다 | 9교시 25쪽 "교사가 약점을 겨냥, 학생이 그 안에서" |
| D5 | **목표 장면**(면접·발표·전화·일상)을 고르고, 모든 계단이 그 장면의 문장을 쓴다 | 7교시 5단계 1번, 대표성 |
| D6 | 매 세션 = 오늘 상태 → **파지 체크** → 운동 A(현재 계단-1) → 운동 B(현재 계단) → **수행 체크** → 비용 보고 → 결과 | 9교시 수행·파지·전이 루프, 파지 5기준 |
| D7 | 파지·수행 체크는 트랙 내내 **같은 문장**(장면 기준 문장)으로 잰다 | 9교시 12쪽 "같은 목표·같은 비교 조건" |
| D8 | 결과는 **세 점**(지난 끝 → 오늘 시작 → 오늘 끝)으로 보여주고, 오늘 끝의 상승은 수행, 오늘 시작이 지난 끝에 가까운 것을 학습이라 부른다 | 9교시 1부 |
| D9 | 계단 진급은 **성공하면 다음**: 수행 체크 기준 충족 + 힘든 정도 ≤3 + 통증 없음 → +1. 통증 또는 힘든 정도 5 → −1 | 9교시 7쪽, 4교시 행동경계 3구간 |
| D10 | 성공 기준은 **결과**로만(방식 제외), 트랙별 핵심 지표 하나 | 8교시 34쪽, 3교시 핵심 정보 |
| D11 | 운동마다 **변형 하나**를 목록에서 순서대로 고른다 (소리·시간·몸·접근 경로 4축). 진단에서 흔들림이 크면 약한 변형만 | 6교시 변동 목록, 8교시 30쪽, 5교시 이력현상 |
| D12 | 녹음은 **상한**이 있다 (최대 길이·준비 시간) | 5교시 29쪽 "한계까지 가지 않는다" |
| D13 | 지시문은 **결과·비유 언어**, 금지문 없음, 마지막 줄은 결과. 몸 지시는 위험·차이 인지·범위 축소 때만 | 8교시 4부, 1교시 64쪽, 5교시 48~50쪽 |
| D14 | 훈련 시작 전 **학습 원리 5줄**을 보여준다 | 9교시 41쪽 |
| D15 | 결과 문구에 낙인 없음("지금 조건의 상태이지 한계가 아님") | 4교시 24쪽 |
| D16 | 세션 로그는 **관찰일지** 꼴(상태·과제·환경·행동 / 기능·비용·다음) | 4교시 54·55쪽 |
| D17 | 구독 시스템 전까지 훈련은 **로그인 사용자에게 무료 개방** | 다회 세션 데이터 없이는 파지 검증 불가 |

## 3. 전이 사다리 (모든 트랙 공통 자극, 트랙마다 관찰할 결과가 다름)

| 단 | 제목 | 남기는 것 / 더하는 것 | 문장 |
|---|---|---|---|
| 1 | "음~" 허밍 | 캐리어만 | — (5초 목표, 8초 상한) |
| 2 | "아~"로 말 흉내 내기 | + 운율(FM·AM) | 장면 기준 문장을 "아~"로 |
| 3 | 부드러운 자음 문장 | + 유성자음(ㄴㄹㅁㅇ) | 유성자음·모음만으로 된 문장 |
| 4 | 실제 첫 문장 | + 무성자음(ㄱㄷㅂ…) | 장면 기준 문장 (파지·수행 체크와 동일) |
| 5 | 두 문장 이어 말하기 | + 길이 | 장면 두 문장 |
| 6 | 쉬어 가며 바로 시작하기 | + 호흡 위치 + 시간 압박(준비 3초) | 장면 문장 + "/" 쉼 표시 |

진단은 1~4단을 오른다. 처음 기준을 벗어나는 계단이 **행동경계**이고 트랙의 시작 계단이 된다. 1~4단 모두 통과하면 5단에서 시작한다.

## 4. 트랙 (고민별 핵심 정보·기준·변형)

| 고민 | 지표 | 핵심 정보 한 줄 | 결과 기준 |
|---|---|---|---|
| 떨림 | jitter (Praat ≤3% / 브라우저 ≤50%) | 소리 끝이 처음과 같은 굵기인가 | 문장 끝까지 기준 안 |
| 작은 목소리 | 평균 dB (진단 기준 −2dB 이내) | 문장 끝이 처음만큼 멀리 가는가 | 기준 음량 유지 |
| 빨라짐 | 초당 음절 2.5~5.5 | 쉼이 들렸는가 | 범위 안 |
| 웅얼거림 | 자가 판단 | 받침과 첫 자음이 들렸는가 | 녹음을 듣고 모든 글자가 구분됨 |

발음은 음성인식이 없어 자가 판단으로 둔다. `phonemeErrorRate.ts`는 인식 텍스트가 생기면 연결한다.

## 5. 데이터

- `user_profiles`: `scene`, `track_concern`, `track_rung`, `track_started_at`, `baseline`(진단 4단 측정, jsonb) 추가
- `training_sessions` (신설): 관찰일지. `kind`(diagnosis|session), `voice_use`, `rung`, `variation_id`, `retention`/`performance`/`rung_measures`(jsonb), `effort`, `pain`, `met_criterion`, `next_rung`
- `user_training_logs`: 아카이브 달력 호환을 위해 세션마다 1행 계속 기록 (`stage_num` = 계단)

마이그레이션: `docs/superpowers/migrations/2026-10-17-training-tracks.sql` (Supabase SQL 편집기에서 수동 실행).

## 6. 화면

- `/training` — 트랙 없음: 학습 원리 5줄 + 장면 선택 → 진단. 트랙 있음: 사다리 위치, 세션 수, 지난 파지 결과, "오늘 세션".
- `/training/diagnose` — 1~4단 녹음 → 경계 → 고민 제안·확정.
- `/training/session` — D6의 7단계.
- 삭제: 사전등록 랜딩, Day 5 선택, `/training/session/[day]`, 옛 운동 컴포넌트.

## 7. 문구 원칙 (2026-10-18 추가)

발성을 모르는 사용자가 녹음을 듣고 맞았는지 바로 판단할 수 있어야 한다. 비유("울림을 넘긴다", "한 줄의 소리", "굵기") 대신 귀로 확인되는 현상(끊김·떨림·작아짐·빨라짐)으로 쓴다. 화면에는 내부 용어(캐리어·운율·파지·변형·전이 사다리·비용)를 쓰지 않는다: 단계, 시작/마무리 녹음, 오늘은 이렇게 해 봐요, 목 상태.

## 8. Out of scope (3차)

- 3회 녹음 뒤 사용자가 먼저 고르기, 피드백 빈도 감축, 대역폭 피드백
- 행동경계 3구간 자동 판별(지금은 D9의 단순 규칙)
- 친구에게 블라인드 A/B, 시간 압박 단계 확장
- 발음 트랙 자동 측정(음성인식)
- 구독 결제
