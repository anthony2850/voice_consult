# 발성 훈련 풀 (Draft) — 4 concerns × 4 exercises = 16

**상태**: 초안. 체계(category/Day 등 상위 구조)가 정해진 후 매핑할 reference.

**날짜**: 2026-06-03

각 concern별로 4단계 progression (L1 토대 → L2 드릴 → L3 통합 → L4 적용)으로 구성. 임상적으로 검증된 일반 발성치료/코칭 기법 기반.

---

## A. 작은 목소리 (small_voice)

목표: 호흡 지지, 공명 배치, 전달력 확보 — 힘으로 짜내지 않고 효율적 음량.

### A-L1. 복식호흡 인지 (Diaphragmatic Breathing Awareness)
- **기법 출처**: Stemple Vocal Function Exercises (VFE) — 발성치료 표준 토대
- **방법**: 누운 자세 + 배 위에 책. 코로 4초 들이마시고 6초 입으로 내쉬기. 손이 위아래로 움직이는 것 관찰.
- **앱 가이드**: 시각 호흡 페이서 (확장/수축 원) + 60초 타이머
- **근거**: 약한 목소리의 가장 흔한 원인은 흉식 호흡 → 성대 하부 압력 부족. 복식호흡이 성대 효율을 위한 기본 압력원.

### A-L2. 빨대 호흡 (Straw Phonation / SOVT)
- **기법 출처**: Titze의 Semi-Occluded Vocal Tract 운동 — 임상에서 가장 폭넓게 권장
- **방법**: 가는 빨대를 입에 물고 음을 내며 유지. 도-레-미 음계로 천천히 상승·하강.
- **앱 가이드**: 빨대 준비 안내 일러스트 + 음정 기준 톤(샘플 재생) + 녹음
- **근거**: 빨대로 입을 좁히면 성도 임피던스 변화 → 성대가 효율적으로 진동. 적은 노력으로 큰 울림. 보컬 트레이너 표준 도구.

### A-L3. 험 → 모음 전환 (Hum-to-Vowel)
- **기법 출처**: Verdolini의 Resonant Voice Therapy
- **방법**: 입 다물고 '음~' 험 (입술/광대 진동 감지). 입을 천천히 열며 '아~'로 전환. 진동감 유지.
- **앱 가이드**: 진동감 시각화 (입술/광대 강조) + 험→모음 사이클 녹음
- **근거**: 전방 공명(forward placement) 훈련. 두개골 앞쪽 공명강을 활용해 적은 힘으로 또렷한 음량. 후두 부담 줄임.

### A-L4. 거리감 시뮬레이션 (Distance Calling)
- **기법 출처**: LSVT LOUD 원리 — "Speak LOUD, not pushed"
- **방법**: 1m / 3m / 5m 거리의 가상 청자에게 같은 문장을 또렷이 전달. 각 거리에서 녹음.
- **앱 가이드**: 거리 게이지 + 녹음 + Praat 데시벨/안정성 측정 + 자기 비교
- **근거**: 일상 볼륨 조절을 운동적으로 훈련. LSVT는 파킨슨 환자 대상이지만 "건강한 큰 소리" 원칙은 일반에 적용.

## B. 떨리는 목소리 (trembling)

목표: 호흡 안정 + 후두 긴장 완화 + 자율신경 진정으로 떨림 감소.

### B-L1. 4-7-8 호흡 (Box-breath variant)
- **기법 출처**: Andrew Weil의 4-7-8 호흡 — 부교감 활성화
- **방법**: 4초 코로 들이마시고 → 7초 멈추고 → 8초 입으로 내쉬기. 4회 반복.
- **앱 가이드**: 시각 페이서 (3구간 색깔 변화) + 카운트다운
- **근거**: 떨림의 큰 원인은 교감 신경 과활성. 길게 내쉬기는 부교감 활성 → 심박·근긴장 감소 → 음성 안정.

### B-L2. 모음 유지 (Sustained Vowel)
- **기법 출처**: Stemple VFE Phase 2 — 발성 안정성 측정·훈련 표준
- **방법**: '아~' 한 호흡에 최대한 길게 유지. 5초 → 10초 목표. 흔들리지 않게.
- **앱 가이드**: 시간 측정 + 실시간 Praat jitter 측정 + 즉시 점수 표시
- **근거**: jitter(주기 변화율)는 발성 안정성 객관 지표. 우리 인프라(Modal+Praat)가 즉시 측정 가능 — 자기 정량 피드백.

### B-L3. 립 트릴 음계 (Lip Trill Scale)
- **기법 출처**: SOVT + 후두 이완 운동 — 보컬 트레이닝 표준
- **방법**: 입술을 부르르 떨며 도-미-솔-미-도 음계 진행. 후두 긴장 풀기.
- **앱 가이드**: 음계 기준 톤 + 녹음
- **근거**: 입술 진동은 후두 근육 긴장 해소 + SOVT 효과로 성대 효율 향상. 떨림 완화에 직접 도움.

### B-L4. 안정된 문장 읽기 (Stable Reading)
- **기법 출처**: Carryover task — SLP 표준 적용 훈련
- **방법**: 정해진 문장을 흔들림 없이 읽기. 사이클 시작/끝 녹음 → 변화 비교.
- **앱 가이드**: 스크립트 + 녹음 + jitter 변화 그래프 + before/after 재생
- **근거**: 일상 발화로 carryover. 데이터로 진척감 + 동기부여.

## C. 빠른 목소리 (fast)

목표: 휴지(pause) 조절, 운율 인지, 의도적 페이싱.

### C-L1. 메트로놈 음절 읽기 (Metronome Syllable Reading)
- **기법 출처**: Pacing therapy — 말더듬·과속 발화 치료에 폭넓게 사용
- **방법**: 60 BPM 메트로놈에 맞춰 한 음절씩 읽기. 80, 100 BPM으로 점진 증가.
- **앱 가이드**: 시각·청각 메트로놈 + BPM 조절 + 녹음
- **근거**: 외부 페이스 동기화로 내부 페이스 인지력 향상. 말더듬 치료에서 검증된 기법.

### C-L2. 의도적 휴지 (Pause Insertion)
- **기법 출처**: Prosodic chunking / Lessac phrasing
- **방법**: 문장을 의미 단위로 끊어 읽기. 각 끊는 자리에서 1초 휴지.
- **앱 가이드**: 끊을 자리 시각 표시(/, ·, 색 강조) 스크립트 + 녹음
- **근거**: 빠른 말의 주된 원인은 휴지 부족. 의도적 휴지로 페이스 자체와 청자 이해도 동시 향상.

### C-L3. 슬로우 섀도잉 (Slow News Shadowing)
- **기법 출처**: 외국어 학습의 shadowing 기법 — 청각 운동 동기화
- **방법**: 차분한 뉴스 앵커 음성(0.75x)을 따라하기. 녹음 후 모델과 비교 재생.
- **앱 가이드**: 모델 오디오 + 녹음 + 비교 재생
- **근거**: 모범 페이스를 청각으로 흡수 → 운동 출력으로 모방. 청각-운동 루프 강화.

### C-L4. 목표 BPM 발화 (Target BPM Speech)
- **기법 출처**: Self-monitoring with biofeedback — SLP 표준
- **방법**: 30초 자유 발화. 시스템이 분당 어절수(BPM) 측정 → 목표(예: 240 BPM)와 비교.
- **앱 가이드**: 자유 녹음 + 자동 BPM 분석 + 점수
- **근거**: 일상 페이스 측정 + 객관 피드백으로 자기 인지. 우리 인프라가 측정 가능.

## D. 발음 웅얼거림 (diction)

목표: 조음기관 정밀화, 자음 명료성, 모음 안정.

### D-L1. 입술/혀 풀기 (Articulator Warmup)
- **기법 출처**: Lessac Method — Articulator NRG 준비 운동
- **방법**: 입술 부르르(30초) + 혀 시계방향/반대방향 회전(30초) + 턱 풀기(30초).
- **앱 가이드**: 동영상 가이드 또는 일러스트 시퀀스 + 타이머
- **근거**: 발음 명료성의 토대는 조음기관 유연성. 운동 전 워밍업은 검증된 효과.

### D-L2. 자음 정밀화 (Consonant Precision Drill)
- **기법 출처**: Lessac NRG Consonant work
- **방법**: ㅂㅍㅁ / ㄷㅌㄴ / ㄱㅋㅇ / ㅅㅈㅊ 자음군 반복. 각 자음의 입 모양/혀 위치 안내.
- **앱 가이드**: 발음 다이어그램 + 녹음 + **음소 정확도 자동 측정**(`phonemeErrorRate.ts` 이미 구현됨)
- **근거**: 발음 명료성 = 자음 정확성. 음소 단위 정밀 훈련이 핵심.

### D-L3. 잰말놀이 (Tongue Twisters)
- **기법 출처**: Hyperarticulation drills — 발성·연기 훈련 표준
- **방법**: 한국어 잰말놀이("간장 공장 공장장", "경찰청 철창살" 등). 느리게 → 빠르게.
- **앱 가이드**: 단계별 속도 가이드 + 녹음 + 음소 점수
- **근거**: 조음 속도와 정확도 동시 훈련. 도전 요소로 동기 부여.

### D-L4. 자연 문장 적용 (Natural Sentence Application)
- **기법 출처**: Carryover task — SLP 표준 마무리
- **방법**: 일상 문장(자기소개, 날씨, 감정 표현 등)을 또렷한 발음으로 읽기.
- **앱 가이드**: 스크립트 풀 + 녹음 + 음소 정확도 측정
- **근거**: 훈련 효과를 일상 발화로 전이. carryover는 모든 SLP 치료의 최종 단계.

## 데이터 모델 매핑 시 고려사항 (후속)

- 각 운동은 `ExerciseUnit` 타입으로 표현 가능. `interaction`이 'record'면 녹음+측정, 일부 운동은 'guided' 필요(L1 워밍업 류).
- 새 interaction 타입이 필요할 수 있음:
  - `'metronome'` — C-L1 빠른 말 메트로놈 운동
  - `'breath-pacer'` — A-L1, B-L1 호흡 페이서
  - `'stopwatch'` — B-L2 모음 유지 시간 측정
- `scriptPool`: D-L4, C-L2, B-L4 등 스크립트 풀 필요
- 측정 인프라 활용:
  - Praat jitter/shimmer: B-L2, B-L4 (떨림 측정)
  - 데시벨: A-L4 (볼륨 측정)
  - 음소 정확도(`phonemeErrorRate.ts`): D-L2, D-L3, D-L4
  - 발화 속도(BPM): C-L4
